# Skylar Li / 李香蓄 · AI Product Manager

Skylar 的中英双语个人主页，面向 HR 和潜在合作方展示 AI 产品能力、项目案例、工作方式与联系方式。

## 当前版本

- 中文与英文可切换，语言选择保存在当前设备。
- 3 个案例采用单页展开阅读，首个案例默认打开。
- 桌面端持续显示联系栏，移动端使用吸顶联系条。
- 真实照片、项目经历、邮箱和社交链接均保留明确的待补充状态，不使用虚构内容。
- 当前只提供本地预览，未公开部署。

## 内容更新

个人资料与中英文文案集中在 `data/profile.ts`。补充内容时应同时更新中英文，并遵守 `codex.md` 中的真实性与目录规则。

职业照片和未来的简历文件放入 `public/`。真实联系地址补齐后，再将 `data/profile.ts` 中对应联系项从不可点击状态改为真实链接。

## 本地使用

```bash
npm install
npm run dev
```

开发完成后运行：

```bash
npm run lint
npm test
```

`npm test` 会先执行正式构建，再验证主页核心内容、双语结构和交互约定。
